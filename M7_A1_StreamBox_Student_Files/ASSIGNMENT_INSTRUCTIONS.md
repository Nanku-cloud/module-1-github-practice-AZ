# Module 7 Assignment 1 — StreamBox: Multi-Screen Streaming App

## Objective
Complete the supplied StreamBox app so users can move between main sections and open different title details using Expo Router.

## Requirements
- Four tabs: Home, Browse, My List, Account
- Root Stack
- Dynamic route `title/[id].js`
- Home navigation with `useRouter()` and `router.push()`
- Browse navigation with `Link`
- Read `id` with `useLocalSearchParams()`
- Display the correct title
- Back navigation works
- Preserve the supplied design
- Meaningful Git commits

## APA 7 Reflection
Write 250–300 words explaining file-based routing, tabs vs stacks, dynamic routes, route parameters, `router.push()`, Back behavior, and one navigation issue you tested.

## Application Evidence
Insert into the same APA document: Home, four tabs, Browse, Neon Horizon details, another title details, tab layout code, Home router code, `[id].js`, clean `git status`, and `git log --oneline --graph --decorate -8`.

Do not submit a repository link.
